# Guides

Ten katalog zawiera praktyczne przewodniki po aktualnej architekturze projektu.

## Od czego zaczac

1. `Coding_Standards.md` - styl kodu, include'y, Doxygen, pointery i ownership.
2. `Entity_Guide.md` - bazowy model encji, colliderow, targetowania i pending spawn.
3. `Level_Guide.md` - level, mapa, navmesh, lokacje i JSON spawn.

## Moduly gameplayowe

- `Enemy_Guide.md` - enemy, ally, `ActorInterface`, targetowanie i `AllyBrain`.
- `Ability_Guide.md` - ability, cooldown, target type i pending spawn.
- `AbilityEffect_Guide.md` - efekty, kolizje, frakcje i debug hitboxow.
- `Interactive_Guide.md` - skrzynie, NPC, teleporty, checkpointy i zasieg interakcji.
- `Item_Guide.md` - itemy, equipment, backpack, `ItemDatabase` i loottable.

## Narzedzia i UI

- `Audio_Guide.md` - efekty, muzyka, playlisty, formaty plikow i glosnosc.
- `UI_Guide.md` - layout UI, HUD, questbook, dialogi i menu.
- `DevLevel_Guide.md` - robocze ustawianie propsow i swiatla.

## Dokument przekrojowy

Szerszy opis runtime leveli i lokacji jest w `../level_system.md`.
